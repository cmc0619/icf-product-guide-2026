# NoBuck — direct-to-concrete window installation

NoBuck is our shorthand for the tested method, not the report's name or a commercial system.

## Primary source

[ICF Field Testing Report, RDH Building Science, BC Housing and BC Ready Mixed Concrete Association](https://www.bchousing.org/publications/ICF-Field-Test-Report.pdf). Phase 3 field testing took place November 11, 2015; Module 4 final test report dated March 22, 2016.

- Appendix II: installation photographs.

## Tested concept

Strip temporary opening formwork, anchor a box-frame window to the concrete core and seal the perimeter using foam backer rod with silicone. The sill detail provides outward drainage and lower-corner weeps. The tested assembly did not use a permanent buck or perimeter flashing membrane. Expanding spray foam is not the tested sealant detail.

| Test | Direct-to-concrete result |
|---|---|
| Phase 2 laboratory water penetration | Pass at 5,000 Pa |
| Phase 3 field water penetration | Pass at 150, 300 and 700 Pa |

Field testing used ASTM E1105 and required no remedial work for Module 4. These are water penetration test results, not structural wind ratings or thermal performance data. Project-specific window anchorage, drainage, sealant compatibility, thermal bridging and code compliance still need design review.
